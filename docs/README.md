# Documentation Overview

This folder provides a quick, high-level overview of the repository so you can start working on the codebase quickly.

## Files

- `architecture.md` – High-level view of the simulation components and data flow.
- `main.md` – Documentation for `main.py` and how to run the simulation.
- `agent.md` – Documentation for the `Agent` class and related logic.
- `environment.md` – Documentation for the `Environment` class and simulation loop.
- `llm_interface.md` – Documentation for the LLM integration and configuration.

Start with `architecture.md` for a bird's-eye view, then dive into individual components as needed.
